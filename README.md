# Agricultural_Market_Analysis
Excited to share my Agricultural Market Analysis Dashboard, built completely using Microsoft Excel 📊🌱

This dashboard provides an interactive overview of agricultural performance across production, cultivated area, yield, crops, states, and seasons.

🔍 Key Features:

📈 Production Trend from 1997–2017
🌾 Production by Crop & State
🌱 Average Yield by Crop
☀️ Production by Season
📊 Dynamic KPI Cards
🎯 Interactive Year, State, Crop & Season Filters

💡 What I learned:

• Data cleaning and transformation
• Power Query & Power Pivot
• PivotTables and PivotCharts
• KPI creation and dashboard design
• Interactive filtering using slicers
• Turning raw agricultural data into meaningful business insights

This project helped me understand how Excel can be used to transform raw data into an interactive analytical dashboard and present insights in a clear, business-friendly way.
